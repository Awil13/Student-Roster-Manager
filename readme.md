I created this Student Roster Manager as a class project. It takes raw student records, turns them into objects, stores them in a roster, and reports on the data. I learned about pointers, memory management, and how header and source files work together. The Student class keeps data private and exposes it with getters and setters. The roster class holds an array of pointers to each student. It has functions to print all students, filter by degree, calculate the average number of course days, remove a student by ID, and flag invalid email addresses.
